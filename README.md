# Stashly

`@stashly_app_bot` · рабочее имя репозитория — `note_keeper`.

Структурированное хранилище знаний в Telegram. Универсальная объектная
модель: коллекции → записи → вложения и заметки, произвольные свойства на
любом объекте, теги, полнотекстовый и структурный поиск.

Cloudflare Workers (webhook) + D1 (SQLite + FTS5) + grammY.

## Структура

```
brand/               логотип: PNG для Telegram, SVG-исходник, генератор
migrations/          схема D1
src/core/            общие мелочи (id, время)
src/domain/          модель и правила: типы свойств, разбор поискового запроса
src/application/     сценарии; о Telegram не знают
src/infrastructure/  D1-репозитории и слой Telegram
tests/               проверка сгенерированного SQL на настоящем SQLite
docs/data-model.md   решения по модели данных и ловушки
```

## Запуск

```bash
npm install
```

Создать базу и записать выданный `database_id` в `wrangler.toml`:

```bash
npx wrangler d1 create note_keeper
```

Применить миграции:

```bash
npx wrangler d1 migrations apply note_keeper --remote
```

Секреты — только через `wrangler secret`, не через `.env` и не в
`wrangler.toml`, иначе токен уедет в git:

```bash
npx wrangler secret put BOT_TOKEN
```

`WEBHOOK_SECRET` — произвольная длинная строка, сверяется с заголовком
Telegram. `ADMIN_SECRET` защищает `/admin/*`:

```bash
npx wrangler secret put WEBHOOK_SECRET
```

Деплой и установка вебхука (одноразово, не при каждом запуске):

```bash
npx wrangler deploy
```

```bash
curl "https://note-keeper.<subdomain>.workers.dev/admin/set-webhook?secret=<ADMIN_SECRET>"
```

## Тесты

```bash
npm test
```

Две части:

1. **Чистые функции** — разбор поискового запроса, вывод типов значений,
   пагинация. Без БД.
2. **Контракт с SQLite** — снимает SQL, который *реально генерируют*
   репозитории, и проигрывает на настоящем SQLite.

Второе важнее первого. Заглушки БД тут бесполезны: все три бага, найденные
при разработке (bm25 внутри JOIN, сырые значения в индексе, `12:34`,
разобранный как фильтр), компилировались и не падали — они видны только на
живом SQLite.

Нужен Python 3 — только для тестов, в рантайме его нет.

## Как пользоваться ботом

Основной вход — не команды. Переслали боту фото, голосовое или текст →
выбрали раздел → запись создана. Любой текст без активного мастера
считается поиском; если ничего не нашлось, бот предлагает сохранить сам
запрос как запись.

Поиск понимает свободный текст и фильтры одновременно:

```
раздел:донхуа оценка>=9 tag:любимое has:фото небеса
```
